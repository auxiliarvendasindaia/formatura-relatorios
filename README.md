# Relatórios de formatura — gestão

Páginas estáticas para a gestão da Indaiá Eventos. Cada relatório fica numa pasta de nome aleatório e a raiz não lista nenhum deles. As páginas trazem `noindex` e o `robots.txt` bloqueia buscadores.

**Este repositório é público.** Aqui só entra versão sem dado pessoal sensível: nada de CPF, telefone, e-mail, link de boleto ou linha digitável.

Atualização manual, sob demanda, sempre no mesmo endereço.
